# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for infrastructure design choices.

## Format

Use the template in `templates/adr-template.md` when creating new ADRs.

## Index

| ADR | Title | Status |
|-----|-------|--------|
| [0001](adr-0001-separate-state-files-per-environment.md) | Separate state files per environment | Accepted |

## Naming Convention

```
adr-NNNN-short-title.md
```

Example: `adr-0001-separate-state-files-per-environment.md`
