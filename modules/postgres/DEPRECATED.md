# DEPRECATED — Do Not Use

This module is **deprecated** and retained only for backward compatibility during the v1.0.0 migration window.

| Replacement | Notes |
|-------------|-------|
| `postgresql-flexible-server` | Use for all new PostgreSQL deployments |
| `postgresql-database` | Application database provisioning |
| `postgresql-configuration` | Server configuration parameters |

**Removal target:** v2.0.0

See [docs/terraform/AUDIT_REMEDIATION.md](../../docs/terraform/AUDIT_REMEDIATION.md) for migration guidance.
