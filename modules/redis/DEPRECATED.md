# DEPRECATED — Do Not Use

This module is a **placeholder** for future Azure Cache for Redis support. It is not implemented and must not be referenced in environment compositions.

When Redis is required, implement a new module or adopt an Azure Verified Module before wiring into environments.

**Removal target:** v2.0.0 (or when `redis` module is fully implemented)

See [docs/terraform/AUDIT_REMEDIATION.md](../../docs/terraform/AUDIT_REMEDIATION.md).
